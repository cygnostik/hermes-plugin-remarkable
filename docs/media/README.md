# Promotional media

- `remarkable-editorial-original.png` preserves the original generated plate: a reMarkable-inspired e-paper tablet and scientific sketches. Created through OpenAI image generation using ChatGPT OAuth. It is editorial artwork, not a device photograph or live plugin result.
- `remarkable-hermes-header.png` is the 1200×600 catalog/README composition. Essential title, maker credit and tablet are inset for the catalog's center crop.
- `remarkable-requests.png` illustrates example requests, not recorded tool output.
- `source/artboards.html` retains the editable layout and exact typography. `scripts/media/render-promo.cjs` renders the two compositions using Node and Playwright available in the invoking environment.

The visual direction combines the paper/engraving and dark editorial families studied in [Nous's design booklet](https://nousresearch.com/wp-content/uploads/2024/03/NOUS-BRAND-BOOKLET-firstedition_1.pdf), without claiming official status or using Nous logos.

Courier New is resolved from the rendering system, not distributed. Oxanium and Departure Mono are distributed with their SIL Open Font License notices in `source/`. The small ProDyn.ai maker signature uses the owner's supplied mark with approval. Brand marks remain their owners' property; the code license does not grant endorsement or impersonation rights.

The notebook capabilities and rendering limits are documented in `../../GUIDE.md` and the root acceptance record. Artwork does not expand that compatibility contract.
